#iPhone Business

Личная система учёта бизнеса по перепродаже iPhone.

Цель проекта

Telegram-бот и Telegram Mini App для управления закупками, складом, продажами, обменами, расходами и финансами.

Проект предназначен для одного владельца. Интерфейс на русском языке, валюта — российский рубль.

Компоненты

* Telegram Bot — быстрые операции, просмотр склада, профиль и уведомления.
* Telegram Mini App — полноценный интерфейс управления бизнесом.
* Backend API — единая бизнес-логика для бота и Mini App.
* PostgreSQL — база данных.
* VPS — размещение приложения и фоновых задач.

Основные разделы Mini App

1. Главная
2. Склад
3. Операции
4. Финансы
5. Ещё

Принципы

* Тёмный минималистичный дизайн в премиальном стиле.
* Адаптация под iPhone без горизонтальной прокрутки.
* Плавные, аккуратные анимации без перегруженных эффектов.
* Подтверждение каждой операции перед сохранением.
* Защита от повторной записи одной операции.
* Единые расчёты финансов для бота и Mini App.
* Корректный учёт себестоимости, прибыли и денежных средств.
* Редактирование операций с пересчётом связанных данных.
* Резервное копирование базы данных.
* Доступ только владельцу.

Важные правила учёта

* Закупка телефона увеличивает стоимость склада, но сама по себе не является расходом, уменьшающим прибыль.
* Прибыль от продажи учитывает себестоимость и прямые затраты без двойного списания.
* Общие расходы уменьшают прибыль за месяц, в котором они оплачены.
* Переводы между собственными счетами не изменяют общий баланс.
* Вывод денег себе уменьшает бизнес-баланс, но не прибыль.
* Начальный баланс и исторические операции не должны повторно изменять текущие денежные средства.

Статус

Подготовка требований и инфраструктуры. Разработка ещё не начата.

Безопасность

Токены, пароли, ключи доступа и другие секреты нельзя хранить в Git-репозитории. Они будут задаваться отдельно на сервере.
